# Instinct Messenger 🤖

بوت مبيعات يرد على عملاء **ماسنجر وإنستجرام وواتساب**، يرشّح المنتجات، ياخد الأوردر ويسجّله، وكل حاجة فيه **قابلة للتحكم من لوحة تحكم عربية** — مفيش أقسام ولا حقول ولا أسعار ثابتة في الكود.

## اللي بيعمله
- **ردود ذكية بـ Claude** بلهجة مصرية مهذبة (الشخصية والتعليمات بتكتبها إنت)، ويفهم **صور العميل** (يلاقي المنتج الشبيه، يقرأ إيصال) ويبعتله **صور المنتجات**.
- **المنتجات من Google Sheet / Excel / CSV**: أي أعمدة (مقاس، لون، خامة…) بتتحول لخصائص تلقائيًا، والأقسام بتتعمل لوحدها، مع تحديث تلقائي. وتقدر تضيف/تعدّل منتجات من اللوحة.
- **تعليمات لكل قسم ولكل منتج** (مثلًا الأحذية: "اسأل عن المقاس الأوروبي") + حقول لازم البوت يسأل عنها قبل الإضافة للسلة.
- **الأوردرات**: يجمع البيانات (الحقول من إعداداتك)، يحسب الشحن **حسب المحافظة**، يعرض ملخص ويطلب تأكيد صريح، ويسجّل. الأوردر يظهر في اللوحة لحظيًا بتنبيه صوتي، ويتبعت لشيت Google (Apps Script) وتليجرام، ويتصدّر Excel/CSV. المخزون بينقص تلقائيًا.
- **أوضاع البيع والخصومات**: أوضاع قابلة للتبديل (عادي / بيع نشط / خدمة عملاء) وقواعد خصم (مثلًا 10% لو العميل هيمشي). البوت **ما يقدرش** يخترع خصم: السيرفر هو اللي بيفرض القواعد والحدود.
- **بيتعلم**: لما يتسأل حاجة ما يعرفهاش بيقول للعميل "هتأكد"، وبيوصلك السؤال. إجابتك مرة واحدة بتتحفظ في **قاعدة المعرفة** وبيستخدمها بعد كده (تلقائيًا أو بموافقتك).
- **ما يهنّكش**: طابور شغل دائم (ما بتضيعش رسائل لو السيرفر وقع)، تجميع رسائل العميل المتتابعة، إعادة محاولة، منع التكرار، مهلة وردّ اعتذار + تحويل لموظف عند الفشل، وصفحة صحة النظام.
- **تحويل لموظف**: بكلمات مفتاحية أو بقرار البوت. وأول ما ترد أنت من اللوحة أو من صندوق الصفحة البوت بيسكت المدة اللي تحددها.

## تشغيل سريع
```bash
npm install
npm start            # http://localhost:3000
npm test
```
بعدها اقرأ **[docs/SETUP.md](docs/SETUP.md)**: خطوات مفتاح Claude، الشيت، الأوردرات، وربط Meta (ماسنجر/إنستجرام/واتساب).

> محتاج Node.js 22.5+ (قاعدة البيانات SQLite مدمجة، مفيش خدمات خارجية للتشغيل المحلي).

## هيكل المشروع
```
src/
  server.js        Express + webhook Meta + تسجيل مهام الطابور
  db.js            SQLite + الإعدادات (كلها قابلة للتعديل) + بيانات أولية
  defaults.js      القيم الافتراضية (برومبت، محافظات، أوضاع، خصومات)
  importer.js      قراءة CSV/XLSX/Google Sheet + ربط الأعمدة + upsert
  catalog.js       المنتجات والأقسام والبحث العربي
  cart.js          السلة، الشحن، الخصم، ملخص الأوردر وحمايته، إنشاء الأوردر
  queue.js         طابور دائم + debounce + إعادة محاولة
  ai/              البرومبت، الأدوات، Claude، الوضع التجريبي، الـ agent
  channels/        Meta (ماسنجر/إنستجرام/واتساب) + إرسال وتقسيم الرسائل
public/            لوحة التحكم (بدون مكتبات خارجية)
docs/              دليل الربط + سكريبت Google Apps Script
test/              اختبارات (تدفق كامل، webhooks، استيراد، حلقة Claude بسيرفر مزيّف)
```

## حدود لازم تعرفها
- **الوضع التجريبي** (بدون مفتاح Claude) قواعد بسيطة للتجربة فقط، مش للعملاء.
- تكامل Claude اتختبر بسيرفر Anthropic مزيّف (شكل الطلبات ودورة الأدوات)، وتكامل Meta اتختبر بأحداث webhook مصطنعة. **التجربة الحقيقية محتاجة مفاتيحك** (دليل الربط).
- واتساب خارج نافذة الـ 24 ساعة (Template messages) غير مدعوم حاليًا.
- الأوردرات بتتنسخ لشيت عبر Apps Script (من غير OAuth). لو عايز كتابة مباشرة بـ Google API ده تطوير لاحق.
